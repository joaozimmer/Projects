# Data Science & Analytics Portfolio

Welcome to my portfolio! Here you will find a collection of practical projects focused on Exploratory Data Analysis (EDA), data processing, predictive modeling, and business solutions using Python and SQL.

---

## 📂 Projects

### 1. [San Francisco Housing Market Analysis (2005)](./sf-housing-analysis/)
- **Description:** Comprehensive EDA on real estate transactions, exploring price distributions, spatial correlations, and geographic mapping using Python.
- **Tech Stack:** Python, Pandas, Seaborn, GeoPandas, Contextily.

### 2. [Fixed Income Portfolio Simulator](./fixed-income-analysis/)
- **Description:** Comparative exploratory analysis and simulation of Brazilian fixed income assets (Tesouro Prefixado, Poupança, CDB, LCI/LCA, and Fundo DI). The project automates compound interest calculations, regressive tax deductions, and generates net yield growth trajectories over a 5-year horizon.
- **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn.
